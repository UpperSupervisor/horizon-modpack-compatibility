# Security

Hopper runs on the machine it is on. It reads your Horizon install and the
files you point it at, talks to the public services its features need and
nothing else, and it has no telemetry and no account.

If you find a way to make Hopper read or write outside its own folder and
Horizon's, or to make it send your data somewhere it shouldn't, report it
privately through GitHub's **Report a vulnerability** button instead of a
public issue.
